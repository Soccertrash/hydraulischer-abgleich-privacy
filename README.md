# hydraulischer-abgleich-privacy

Veröffentlichte Datenschutzerklärung der Android-App **Hydraulischer Abgleich**
(Paketname `de.pauli.hydraulischerabgleich`).

Die Seite liegt unter <https://soccertrash.github.io/hydraulischer-abgleich-privacy/> (GitHub Pages
aus `main` / Root) und ist die URL, die in der Play Console unter *App-Inhalte →
Datenschutzerklärung* eingetragen wird. Play verlangt sie für diese App, weil sie Kamera- und
Medienzugriff deklariert.

Der App-Code liegt in `Soccertrash/HydraulischerAbgleich`. Ändert sich das Verhalten der App —
neue Berechtigung, neue Datenart, Netzwerkzugriff —, muss diese Seite mitgeändert werden.
